🧠 שלב 1 — Anthropic API Key
המוח של הסוכן. חינם ל-$5 קרדיט התחלתי.
  1. לחץ: console.anthropic.com/settings/keys ↗
  2. הרשם עם Google / אימייל
  3. לחץ Create Key ← תן שם כלשהו ← לחץ Create Key
  4. העתק את המפתח שמתחיל ב- sk-ant-api03-...
  5. חזור לכאן והדבק
💬 שלב 2 — WhatsApp Cloud API
מאפשר לסוכן לשלוח ולקבל הודעות WhatsApp.
  1. כנס ל: developers.facebook.com/apps ↗
  2. לחץ Create App ← בחר Business ← Next
  3. תן שם לאפליקציה ← לחץ Create App
  4. גלול ומצא WhatsApp ← לחץ Set up
  5. לך ל: WhatsApp → API Setup
  6. מתחת ל-"From" — העתק את Phone Number ID
  7. מעל — לחץ Generate access token ← העתק
🚀 שלב 3 — פריסה ל-Railway (ענן חינמי)
Railway מריץ את הסוכן 24/7 ללא שום מחשב מקומי.
  1. כנס ל: railway.app ↗ ← הרשם עם GitHub
  2. לחץ New Project ← Deploy from GitHub repo
  3. בחר את ה-repo: eliesouffann-tech/Coo-contract
  4. Railway יתחיל לבנות אוטומטית
  5. לך ל: Settings → Networking → Generate Domain ← לחץ
  6. העתק את ה-URL שנוצר (נראה כך: xxx.up.railway.app)
  7. חזור לכאן והדבק
⚙️ חיבור Meta אוטומטי מומלץ — חוסך צעד ידני
עם App ID ו-App Secret — הסוכן יגדיר את ה-webhook אצל Meta לבד.
  1. חזור לאפליקציה ב-Meta
  2. לך ל: App Settings → Basic
  3. העתק App ID (מספר) ו-App Secret (לחץ Show)
