אשף הגדרה — בוא נגדיר הכל ביחד

👋 ברוך הבא!
האשף ינחה אותך דרך 4 שלבים קצרים. בסוף הסוכן יעבוד לחלוטין — יענה לך ב-WhatsApp, יזכיר, יתזמן פגישות ויענה בשמך לאנשים אחרים.
  1. מפתח Anthropic (Claude AI) — בחינם להתחלה
  2. מפתח WhatsApp Cloud API (Meta) — בחינם
  3. מפתח ngrok — בחינם
  4. חיבור אוטומטי ל-Meta + הפעלה
🧠 שלב 1 — Anthropic API Key
Claude AI — זה המוח של הסוכן.
  1. כנס ל: console.anthropic.com/settings/keys
  2. לחץ "Create Key"
  3. תן שם (למשל "WhatsApp Agent"), לחץ Create Key
  4. העתק את המפתח שמתחיל ב- sk-ant-
💬 שלב 2 — WhatsApp Cloud API
מפתח Meta לשליחת וקבלת הודעות WhatsApp.
  1. כנס ל: developers.facebook.com/apps
  2. לחץ "Create App" ← בחר "Business" ← Next
  3. תן שם לאפליקציה ← לחץ "Create App"
  4. במסך הבא, מצא "WhatsApp" ולחץ "Set up"
  5. לך ל: WhatsApp → API Setup
  6. מתחת ל-"From" — Phone Number ID (מספר ארוך)
  7. מתחת ל-"Temporary access token" — העתק את הטוקן
🌐 שלב 3 — ngrok
ngrok מאפשר ל-Meta להגיע לשרת שלך. בחינם לחלוטין.
  1. כנס ל: dashboard.ngrok.com/signup (הרשמה עם Google)
  2. לאחר ההרשמה לך ל: dashboard.ngrok.com → Your Authtoken
  3. לחץ "Copy" ליד ה-token
⚡ חיבור Meta אוטומטי מומלץ
עם App ID ו-App Secret — הסוכן יגדיר את ה-webhook אצל Meta לבד, ללא שום פעולה נוספת מצדך.
  1. חזור ל: developers.facebook.com/apps
  2. לחץ על האפליקציה שיצרת → App Settings → Basic
  3. העתק App ID ו-App Secret (לחץ Show)
🎙 הודעות קוליות אופציונלי
מפתח OpenAI להמרת הודעות קוליות לטקסט. אפשר לדלג ולהוסיף מאוחר יותר.
⚙️ מגדיר הכל...
📋 צעד אחרון — חיבור Meta
עוד פעולה אחת קטנה ב-Meta Developer Console — פחות מדקה.
  1. כנס ל: developers.facebook.com/apps ← לחץ על האפליקציה שלך
  2. לך ל: WhatsApp → Configuration
  3. לחץ "Edit" ליד Webhook והכנס את הפרטים הבאים:
  1. לחץ "Verify and Save"
  2. מתחת ל-"Webhook fields" — לחץ Subscribe על messages
  3. חזור לכאן ולחץ "סיימתי"
