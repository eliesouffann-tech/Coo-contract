# WhatsApp AI Agent

סוכן AI אישי ל-WhatsApp — עונה בשמך, קורא מסמכים, מזכיר לך דברים, וזוכר הכל.

---

## מה הסוכן יכול לעשות?

- **לענות בשמך** — לאחר הגדרת פרופיל, עונה לאנשים אחרים בסגנון שלך
- **לקרוא מסמכים ותמונות** — שלח PDF, Word, תמונה — הסוכן ינתח ויענה
- **לקבוע תזכורות** — "תזכיר לי מחר ב-9 לצלצל לדוד" → תזכורת אוטומטית
- **לזכור מידע** — "תזכור שמספר עו"ד שלי הוא..." → שמור לתמיד
- **לעזור בכל** — כתיבה, מחקר, חישובים, תרגומים, עצות

---

## הפעלה — 2 פקודות

**פקודה 1 (פעם אחת):**
```bash
npm run setup
```

**פקודה 2:**
```bash
npm start
```

השרת מדפיס הוראות מדויקות לחיבור ה-webhook ב-Meta.

---

## פקודות WhatsApp

| פקודה | פעולה |
|---|---|
| `/profile` | הגדר את הפרופיל שלך (שם, תפקיד, סגנון) |
| `/notes` | הצג את כל המידע השמור |
| `/reminders` | הצג תזכורות פעילות |
| `/reset` | נקה היסטוריית שיחה |
| `/help` | הצג עזרה |

## מבנה הקוד

```
src/
├── index.js        # שרת + ngrok + הפעלה
├── claude.js       # Claude Opus 4.8 + כלים + זיכרון
├── tools.js        # תזכורות, זיכרון, פרופיל
├── memory.js       # אחסון מתמיד (JSON)
├── scheduler.js    # מנוע תזכורות (node-cron)
├── whatsapp.js     # WhatsApp Cloud API
└── media.js        # קריאת מסמכים ותמונות
data/               # נוצר אוטומטית
├── profile.json    # פרופיל הבעלים
├── notes.json      # מידע שמור
├── reminders.json  # תזכורות
└── conversations.json # היסטוריית שיחות
```
